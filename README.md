# 21 点

Koishi 21 点插件，支持玩家对战和庄家模式。

## 安装

```sh
yarn add koishi-plugin-card-21-game
```

在 Koishi 中启用，并安装 `database` 服务。货币模式还需要 `monetary` 服务。

## 指令

发送 `bj.来一局` 开桌；加 `-n` 开启玩家对战。发送 `bj.下注` 入座，下注金额按余额随机确定。之后发送 `bj.开始`，或等待倒计时。

| 指令 | 裸词 | 说明 |
| --- | --- | --- |
| `bj.下注` | `下注` | 入座 |
| `bj.开始` | `开始` | 发牌并进入下一阶段 |
| `bj.要牌` | `要牌` / `h` | 要牌 |
| `bj.停牌` | `停牌` / `s` | 停牌 |
| `bj.加倍` | `加倍` / `d` | 首轮加倍 |
| `bj.分牌` | `分牌` / `p` | 起手对子时分牌 |
| `bj.投降` | `投降` | 开局 5 秒内投降 |
| `bj.保险` | `保险` | 庄家明牌为 A 时购买保险 |
| `bj.战绩 [@某人]` | — | 查询战绩 |
| `bj.排行榜` | — | 查看盈亏排行 |
| `bj.结束` | — | 结束当前牌局 |

目标是在不超过 21 点的前提下尽量接近 21。Blackjack 赔率为 3:2；庄家点数低于 17 时必须要牌。余额不足时，玩家每天可领取一次救济资金。

## 显示与交互

发送 `bj.显示 文字` 或 `bj.显示 图文` 切换个人显示偏好。同一机器人中的配套插件共享选择，重启后恢复图文。图文模式中的信息图片附带文字说明；作品素材与感官测试的适用边界见 [设计系统](./DESIGN_SYSTEM.md)。

本次更新：下注金额由用户指定，省略时采用最低注额；新增 bj.延长；保险和投降窗口调整为 30 秒；退款与赔付核对记录、输入冲突检测和完整排行榜。

出现入账待核对提示时，管理员可用 `bj.待核对` 查阅记录；核对实际流水并按需人工补发后，再用 `bj.确认入账 编号` 标记。标记不会执行转账，请勿在入账状态不明时重复补发。
