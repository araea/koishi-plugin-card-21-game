# koishi-plugin-card-21-game

21 点 · 完整赌场规则，支持 PVE 与 PVP

## 安装

```sh
yarn add koishi-plugin-card-21-game
```

在 Koishi 配置中启用，并提供 database 服务；金币模式还需要 monetary 服务。

## 指令

发送 `bj.来一局` 开桌，加 `-n` 启用 PVP。发送 `bj.下注` 入座，注额由系统按余额随机安排；再发送 `bj.开始` 或等待倒计时。

对局中的动作写成 `bj.动作`，也接受裸词：

| 动作 | 裸词 | 说明 |
| --- | --- | --- |
| `bj.下注` | `下注` | 入座，注额由系统按余额随机安排 |
| `bj.开始` | `开始` | 发牌并进入下一阶段 |
| `bj.要牌` | `要牌` / `h` | |
| `bj.停牌` | `停牌` / `s` | |
| `bj.加倍` | `加倍` / `d` | 首轮将注金翻倍 |
| `bj.分牌` | `分牌` / `p` | 起手对子可用 |
| `bj.投降` | `投降` | 开局 5 秒内可用 |
| `bj.保险` | `保险` | 庄家明牌为 A 时可用 |

对局管理：

| 指令 | 说明 |
| --- | --- |
| `bj.战绩 [@某人]` | 查询战绩 |
| `bj.排行榜` | 查看盈亏排行榜 |
| `bj.结束` | 强制结束当前对局 |

点数不超过 21 且尽量接近 21。Blackjack 赔率 3:2，庄家点数小于 17 时必须要牌。余额用尽时，下注会自动领取每日一次的东山再起资金。
